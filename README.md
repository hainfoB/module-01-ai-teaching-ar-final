# Séance 01 — Principe CONTEXTE

Page HTML autonome, responsive et trilingue (العربية · Français · English) pour une session de 150 minutes destinée aux enseignants.

Ouvrir `index.html` directement dans un navigateur. Le document contient 175 prompts pédagogiques détaillés, l’évaluation sommative, l’éthique et la confidentialité, l’histoire de l’IA générative en cinq minutes, ainsi qu’un CV/portfolio public en timeline.
